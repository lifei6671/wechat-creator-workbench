# 浏览器主题回归

`workspace-shortcuts.spec.ts` 挂载真实快捷键设置，模拟 Windows／macOS 平台标识，在 Chromium、WebKit 中覆盖九个录入控件、默认复制及阅读／预览组合、重复键冲突、与切换视图的双向冲突、Esc 取消、清除持久化和恢复默认键位，并在 100%／150% 缩放下检查紧凑行高、完整错误占位及标签、控件的垂直对齐。实际工作台的会话测试验证即时生效、当前草稿复制、请求锁及编辑器按键隔离；平台标识模拟不等于 macOS 真机验证。

`tab-replacement.spec.ts` 使用真实 `DocumentTabs`，在 Chromium／WebKit 的正常及减少动态效果设置下，记录替换中间标签时的全部子节点变更，确认标签数量不会短暂增加、旧文稿没有退出占位，且原位置和相邻标签顺序保持；另检查新标签仍追加显示。会话测试覆盖实际文章点击到替换标记的接线，单元测试保留主动关闭标签的动画及标记只消费一次的回归。

`entry-open.spec.ts` 挂载真实文章行，分别模拟 Windows／macOS 的平台标识，在 Chromium、WebKit 中验证 Ctrl／⌘ 单击临时新标签打开。覆盖目录、置顶、导入列表、搜索标题和时间流，检查普通单击及 Enter 遵循默认方式，搜索展开和置顶按钮不会误开文章，右键仍显示菜单。平台标识模拟不等同于 macOS 真机验证。

```sh
pnpm install --frozen-lockfile
pnpm exec playwright install chromium webkit
pnpm test:browser
```

使用 [Playwright Test](https://github.com/microsoft/playwright) 的 Chromium、WebKit 项目，固定工具版本并复用两个引擎的同一份断言。测试自动启动 1421 端口的 Vite，退出时关闭服务；测试结果及失败 trace 写入忽略目录 `output/playwright/test-results`。现有 Windows、macOS CI 桌面矩阵运行相同命令。

`theme-quotes.spec.ts` 覆盖 9 套主题、LF/CRLF 原文、单段及三段引用、13 类三段提示块，比较实际 `DocumentEditor` 的编辑／阅读模式和预览、公众号复制、HTML 导出结果。断言普通段落、末尾段落的计算边距、实际段间距离，以及切换模式后原文不变。夹具位于 `apps/desktop/tests`，不参与生产入口。

引用样式必须在真实引擎中验证：当前 jsdom 对 `margin: 0 0 20px; margin-bottom: 0;` 的长短属性覆盖解析与浏览器不同，单元测试不能替代这组回归。跨平台测试不比较字体像素、整页高度或不同系统的字形。

`footnote-layout.spec.ts` 使用同一 Markdown 样稿和实际 `DocumentEditor`，覆盖 9 套主题、编辑／阅读模式、340px／840px 栏宽、100%／125% 缩放，以及技术主题的 CRLF。通过文本 Range 的实际行框检查常规编号完整、首行对齐、英文单词不被拆开、长网址可以折行、极长自定义标识不挤垮正文且不溢出；同时验证作者硬换行保留、没有新增硬换行和原文不变。

`folder-colors.spec.ts` 覆盖目录纯颜色修改、重新编辑、恢复默认、自定义颜色的鼠标／键盘原生焦点移交、Esc 取消、重复保存锁和固定错误占位，并检查画布调色板的关闭行为及无关重渲染不覆盖颜色草稿。原生对话框的焦点丢失通过 DOM 事件模拟；测试不操作系统选色器本身。浏览器单例用例预算为 60 秒，断言仍使用默认等待时间，兼顾 Windows WebKit 的冷启动耗时。

目录颜色显示回归挂载真实 `Explorer`，通过右键菜单编辑并保存后，断言底板的计算背景色及最终 SVG 的白色 `color`／`stroke`，同时检查底板尺寸、圆角、图形居中和编辑前后的文字对齐。覆盖目录树、时间流、明暗外观、嵌套目录、展开图标、切换图标、自定义颜色、125% 缩放、重新加载及默认灰色恢复，并确认文章图标不受影响，避免只检查外层属性而漏掉 SVG 的 CSS 覆盖。

`status-indicators.spec.ts` 挂载真实状态栏，覆盖 MCP 运行、停止、读取与异常，以及同步阶段、上传、冲突、等待、暂停、未连接与凭据异常。Chromium／WebKit 在明暗外观及正常／减少动态效果下验证 Radix 状态颜色、6px 小点位置、固定按钮宽度、仅处理状态呼吸、静止状态不持续动画、悬停／键盘聚焦详情和原设置入口。会话测试补充原生 MCP 事件、读取失败恢复与同步阶段接线；浏览器引擎回归不等同于 macOS 真机验证。

`ai-citations.spec.ts` 通过真实 AI 面板加载历史消息，检查「全文」「当前章节」「不引用正文」位于正文上方，字号、Radix 浅色边框、4px 间距和靠右对齐；覆盖无标签及选区引用、明暗外观、320px／520px 宽和 100%／150% 缩放，并验证复制失败的固定占位不会推动标签。Chromium 与 WebKit 共用断言，允许 WebKit 缩放下滚动宽度与可视宽度的 1px 整数舍入差异。

`wechat-publication.spec.ts` 挂载实际公众号侧栏与渲染器，覆盖默认 5 篇、键盘排序、选择器多选并超过 5 篇、人工删空、调整生成数量、重新推荐及撤销、复制列表、默认设置未失焦时保存屏障、深色布局无横向溢出。Chromium 和 WebKit 共用断言；原生 IPC、系统剪贴板和 macOS 真机仍由原生验收验证。


`folder-transitions.spec.ts` 检查目录高度的真实中间帧、折叠期间的不可交互状态、快速反向操作、浮层退场反向衔接，以及运行中切换减少动态效果。`status-indicators.spec.ts` 另检查 Tooltip 退场时仍然可见并产生部分透明度，防止定位标志提前隐藏内容。

`workspace-resize.spec.ts` 补充设置退场与焦点恢复、关闭后的新弹窗不会被旧回调清除、取消危险操作后立即 Enter 不会确认、手动调宽期间所有布局缓动关闭，以及在合法中间宽度接管右侧栏和目录栏时边界不跳变。初始布局恢复不做动画，因此拖动用例等待实际目标宽度就绪。`workspace-resize.html?edit=1&long=1` 提供 1000 个重复段落的长文稿夹具，用于在生产构建中独立测量；不将开发模式耗时或单台机器的帧间隔作为所有设备的性能保证。
