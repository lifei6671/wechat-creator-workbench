# 图片画布编辑窗口交互原型

状态：待用户确认。依据 [技术方案](../../image-canvas-technical-design.md) 制作，采用项目现有的 Radix Slate / Indigo 配色、紧凑布局、0.5px 分割线和按钮反馈。

入口：[index.html](./index.html)。本机预览地址为 `http://127.0.0.1:4317/`，需要预览服务正在运行。HTML、CSS、JavaScript 与示例图片位于同一目录，无 CDN 或安装步骤，也可以通过其他静态文件服务预览。

## 原型范围

可以体验单图美化、多图拼接、画布平移和缩放、单选/多选、框选、拖动、四角等比缩放、属性输入、旋转、翻转、对齐、层级、删除及撤销/重做。背景支持纯色、渐变、抽象壁纸和透明预览，留白、圆角、阴影直接改变画面。

左侧「添加图片」可以选择内置示例或本机文件，也支持拖入与粘贴 PNG、JPEG、WebP。本机文件仅由浏览器读取；刷新页面即丢失本次演示状态，切换单图/多图演示会重置场景。示例来自本次提供的三张参考图片，原文件按原样复制，界面以裁剪视口展示其中内容，不下载外部素材。

顶部「模拟状态」展示保存、离线、同步冲突和素材缺失。导出、复制、应用及冲突处理只演示交互，不写入剪贴板或文件，不替换真实正文，不持久化工程，也不连接云端。「保留两份」只演示退出冲突状态，不创建真实工程副本。

裁剪采用固定内缩范围预览并确认，尚未制作自由拖动裁剪边界。多选只演示共同移动、对齐和属性修改；四角缩放作用于当前拖动的图层。图层侧的显示图标仅作可见状态展示，不是隐藏开关。真实素材库、成品编码、精确旋转后的变换和应用事务留待功能实施。

## 新增可见元素及文案

| 区域、元素及文案 | 最终用户需要它的原因 |
| --- | --- |
| 标题「编辑图片」、关闭按钮 | 识别任务并返回正文 |
| 底部「草稿已保存」「正在保存…」「已保存到本机」 | 在统一位置了解当前草稿的保存状态 |
| 「复制图片」「另存为」「应用到文章」 | 分别取得成品或放回文章位置 |
| 选择、平移、添加图片、显示图层 | 操作对象、移动视口并管理输入 |
| 撤销、重做 | 恢复或重新执行当前编辑 |
| 画板边界及像素尺寸 | 识别最终导出范围 |
| 「图层」、图片名称、缩略图和选中状态 | 找到并选择具体图片 |
| 缩小、百分比、放大、适应画板 | 定位画板并控制查看精度 |
| 属性标签「画板」「图片」及选中数量 | 切换整体设置与选中对象设置 |
| 「画板尺寸」、宽、高、原比例、1:1、4:3、16:9 | 精确控制成品大小与比例 |
| 「背景」、纯色、渐变、壁纸、透明、预设色块、颜色值 | 设置整体视觉背景 |
| 「选择背景图片」 | 使用自己的壁纸 |
| 「图片样式」、四周留白、圆角、阴影 | 控制原图与背景的视觉关系 |
| 图片名称、X/Y、宽高、比例锁定 | 精确定位和调整图片 |
| 「裁剪」「完成裁剪」、旋转、翻转、删除 | 调整图片可见内容和方向 |
| 「排列」、左对齐、水平居中、右对齐、上移/下移层级 | 对齐图片并控制遮挡顺序 |
| 「图片拼接」、横向、纵向、宫格、间距、列数 | 快速排好多图 |
| 「导出」、PNG、JPEG、WebP、倍率与输出尺寸 | 选择输出参数并确认大小 |
| 右键菜单「复制图层」「移到顶层」「删除图层」 | 就近处理选中图片 |
| 底部离线、冲突、等待原图状态及固定错误区 | 理解暂不可输出或需要处理的问题 |
| 空格平移、滚轮缩放提示 | 发现不明显的画布操作方式 |
| 冲突窗口「保留本机版本」「采用云端版本」「保留两份」 | 选择需要保留的编辑结果 |
| 导出预览、文件名、尺寸与取消 | 在取得图片前确认范围和参数 |
| 返回文章后的「继续编辑图片」 | 在演示中重新打开当前草稿 |

「交互原型」、单图/多图演示选择、模拟状态、深浅色切换、「示例素材」、演示保存和原型边界说明只用于设计评审，不属于正式产品界面。

## 验证范围

已在本机 Playwright Chromium 中完成 33 项交互检查，覆盖三种拼接、选择及属性切换、拖动、方向键微调、撤销、裁剪演示、背景、缩放、本机加图、导出反馈恢复、离线/冲突/素材缺失、应用返回、浅色/深色令牌及 1440×900、1000×640 布局；额外验证多选后的场景重置、逐层上移/下移、小画板加图和单一草稿状态。页面无 JavaScript 运行错误，示例图片加载完整；这不等同于真实 Windows Tauri 或 macOS WKWebView 验收。

正式实施前仍需确认本原型布局与交互，并按技术方案完成持久化、正文接入、资源生命周期和云端同步。
