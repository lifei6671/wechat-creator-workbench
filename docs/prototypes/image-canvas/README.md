# 图片编辑画布交互原型

状态：第二版已获批准，并用于产品实施；实际功能及验证范围见[验收记录](../../image-canvas-validation.md)。本目录保留独立交互原型，依据 [技术方案](../../image-canvas-technical-design.md) 与 [Pimg.app](https://pimg.app/zh) 的实际单选、多选交互制作，使用项目的 Radix Slate / Indigo 配色。

入口：[第二版原型](./index-v2.html)，本机预览地址为 `http://127.0.0.1:4317/index-v2.html`。预览服务需要保持运行，亦可使用其他静态文件服务。文件不依赖 CDN，也不需要安装组件。

## 交互结构

始终只有一个画布。默认选中一张图片，继续添加素材不会切换页面；单选、多选与空白选区决定属性面板和底部工具栏中的操作。

- **单选图片**：显示尺寸、原图尺寸、比例锁定、不透明度，以及裁剪、旋转、翻转、复制一份和删除。多选后直接单击一张图片可回到单选，拖动则保留整组选区。
- **多选图片**：显示横向、纵向、宫格及自由摆放，提供统一尺寸、间距和列数。点击、Shift 多选、框选、顶部全选及图层列表共用同一选区。
- **选择画板**：点击空白处、左侧背景工具或右栏画板设置，显示画板尺寸和比例。背景、留白、圆角及阴影可在同一面板调整。

画布占满窗口，文档入口、视图工具、左侧工具条、属性面板和底部操作栏浮动于其上。图层列表默认收起，位置与层级默认折叠。原型设置收在右下角，不占用产品主要操作区域。

拼接保留独立图层，切换布局以原始裁剪尺寸计算统一尺寸，避免反复切换导致图片不断变小。追加图片先暂放在画板外，并自动调整视图；原图已选中时，新图片加入同一选区，可直接拼接。拼接后的留白仍针对该组图片生效，不依赖当前是否选中；自由摆放时留白按图片边界调整画板。

## 原型边界

本机图片只由浏览器读取，刷新后不保留本次编辑。复制、导出、应用、保存和同步状态都是交互演示，不写入剪贴板或文件，不修改真实文章，不连接云端。冲突中的「保留两份」只演示选择后的返回状态，不创建真实工程副本。

裁剪仍使用固定内缩范围展示确认流程；缩放手柄只缩放被拖动图层，旋转后的精确手柄几何及生产素材库尚未接入。图片位置、尺寸、旋转、不透明度、背景、留白、阴影及三种布局可直接在原型内调整，不代表已有正式工程数据格式。

示例图片来自本次提供的截图，原文件按原样保存。初始图片以裁剪视口显示最新截图中的城市桌面区域；其他素材使用前一轮参考截图，不请求外部图片服务。

## 可见元素与文案

| 区域、元素与文案 | 最终用户需要它的原因 |
| --- | --- |
| 返回按钮、标题「编辑图片」、「文章配图」 | 识别当前编辑对象并返回文章 |
| 撤销、重做 | 恢复或重新执行画布编辑 |
| 缩小、百分比、放大、显示全部内容 | 控制视图并找回画板和暂放素材 |
| 全选图片 | 无需拖框就能选择全部图片进行拼接 |
| 选择工具、平移画布 | 区分移动图片和移动查看位置 |
| 添加图片 | 在同一画布继续导入素材 |
| 画板与背景、画板设置 | 直接调整输出范围和背景 |
| 图层列表、缩略图与名称 | 找到并选择重叠或位于画板外的图片 |
| 画板边界、画板尺寸及选中图片尺寸 | 区分最终输出范围与图层大小 |
| 面板标题「图片」「已选 N 张图片」「画板」 | 表明当前属性针对的对象 |
| 单选时的图片文件名 | 确认正在修改哪张图片 |
| 图片宽高、比例锁定、原图尺寸和缩放比例 | 精确调整图片大小，并判断缩放关系 |
| 不透明度 | 调整图片叠加时的可见程度 |
| 拼接布局、横向、纵向、宫格、自由摆放 | 在当前选区直接排列多张图片 |
| 统一尺寸、图片间距、宫格列数 | 控制多图布局的比例与间隔 |
| 画板宽高、1:1、4:3、16:9、3:4 | 设定成品的尺寸和比例 |
| 背景、纯色、渐变、壁纸、透明、背景预设、颜色值和自选图片 | 设置成品背景并使用自有素材 |
| 四周留白、圆角、阴影 | 调整图片与背景之间的视觉关系 |
| 位置与层级、X/Y、左对齐、水平居中、右对齐、上移/下移一层 | 提供精确位置输入和不依赖拖动的操作路径 |
| 底部裁剪、完成裁剪、旋转、翻转、复制一份和删除 | 就近处理当前选中的图片 |
| 底部应用到文章 | 将当前画板成品放回文章位置 |
| PNG、JPG、WebP、倍率、输出尺寸、复制和另存为 | 确认输出参数并取得成品 |
| 底部草稿状态及固定错误区域 | 识别保存、离线、冲突和图片不可用状态 |
| 添加窗口中的本地图片、素材库、选择标记和添加数量 | 在当前画布追加一张或多张素材 |
| 导出预览、文件名、尺寸和返回编辑 | 确认输出内容与范围 |
| 冲突窗口中的保留本机、采用云端和保留两份 | 选择需要保留的版本 |

右下角的原型预览设置、明暗切换、状态模拟、恢复初始画布、上一版入口、示例素材标记，以及演示保存和原型边界说明，仅服务设计评审，不进入正式产品界面。

## 参考观察与验证

已通过内置浏览器查看 Pimg.app 的实际页面，使用其示例素材观察多选拼接工具，再单击图片检查单图编辑工具。参考其按选区呈现工具、浮动面板和底部操作栏，不复制其品牌、文案或素材库。

第二版已在内置浏览器完成 30 项检查，覆盖最小桌面 1000×640 和默认窗口布局、追加素材、单选/多选切换、整组拖动与撤销、实际键入尺寸、裁剪演示、旋转、三种拼接、往返切换布局尺寸稳定、背景、导出预览、浅深色、离线、冲突、素材缺失及应用返回。补充验证自选壁纸在导出预览保留、取消选区后的拼接留白及自由布局留白。可见素材正常加载，页面无运行错误。尺寸检查采用实际键入验证。

检查仅针对独立原型，不等同于 Windows Tauri、macOS WKWebView、真实公众号输出或云同步验收。
