# 时间流状态与审查记录原型

入口：[交互原型](./review-history-and-timeline.html)。样例数据仅用于演示。

## 可见元素与用途

| 区域 | 元素或文案 | 用途 |
| --- | --- | --- |
| 时间流 | 草稿、待发布、已发布等既有状态名称 | 在时间前辨识文章状态，沿用内容属性的名称；无状态时不占位。 |
| 时间流 | 12px 描边状态标签 | 通过文字及不同颜色共同区分状态，边框为 0.5px。 |
| 审查面板下方 | 审查记录 | 集中查看当前文章保留的检测结论。 |
| 记录列表 | 文章标题、检测时间 | 沿用 AI 对话记录的单行布局，帮助辨认记录；仅展示与当前文章 ID 关联的记录。 |
| 记录列表 | 删除图标 | 删除该条缓存，悬停或键盘聚焦时出现，触屏上常显。 |
| 记录标题右侧 | 清空 | 一次删除当前文章全部审查记录，不影响其他文章或用量统计。 |
| 记录展开区 | 全文检测或选区检测、朱雀文本检测、三类比例 | 只查看该次检测结论，不展示原文或恢复正文标记。 |
| 空列表 | 暂无审查记录 | 说明当前没有保留的结果。 |
| 操作反馈 | 处理中状态、完成状态和固定错误区域 | 防止重复操作并就近展示失败原因。 |

记录使用既有 30 天缓存，并通过文章 ID 关联。相同文本可复用检测结果，各篇文章独立保留检测范围和标题；单条删除与清空只影响当前文章。旧缓存没有文章 ID 时不展示，之后通过主动检测命中缓存可建立关联，不额外保存原文。记录不进入文档、发布、备份或同步。

原型顶部的深浅色开关仅用于评审，不进入生产界面。中间的文章及检测数据为示例；本次不调整既有检测操作区。
