# 文章审查原型说明

状态：用户已确认布局与文案，生产前端按此实现。原型保留供追溯。

打开同目录的 `article-quality-review.html` 即可预览。原型复用仓库现有 Radix 颜色样式，因此需保留其在仓库中的路径。顶栏仅用于切换原型状态，所有检测、占比、用量和时间均为合成示例，不请求服务、不保存密钥。

## 设计范围

对象为正在修改公众号草稿的作者，主要操作为检测、跳转复核、修改、复检。采用现有冷灰工作区和 350px 右栏；正文与审查列表并排，沿用文章、正文、选区、复核、草稿、发布等已有业务概念。颜色使用 Radix slate、indigo、amber、yellow、red、green，分别承担结构、动作、两类标记、错误与按钮完成反馈。

列表片段与正文装饰一一关联，修改正文即撤下旧标记。使用三类独立占比代替混合总分，使用紧凑条目代替大块指标卡片，保留现有编辑工作区代替新增独立检测页面。

## 新增可见元素及文案

| 区域和元素 | 文案或内容 | 最终用户需要它的原因 |
| --- | --- | --- |
| 右栏入口 | 文章审查 | 打开审查操作与结果，不混入 AI 助手。 |
| 面板标题 | 文章审查 | 确认当前右栏用途。 |
| 检查项名称 | AI 文本检测 | 明确本次检测能力。 |
| 设置图标及可访问名称 | 审查设置 | 直达现有设置窗口中的配置页。 |
| 全文动作 | 检测全文 | 主动提交当前正文快照。 |
| 选区动作 | 检测选区 | 只检测当前选中的文字。 |
| 范围说明 | 不含代码、公式、表格与图片。 | 避免将被排除内容误认为已检测。 |
| 固定错误位 | 请求超时，是否扣减额度尚不确定。等实际错误 | 网络失败时说明原因，不挤动布局。 |
| 未检测状态 | 主动检测当前正文或选区。 | 说明当前尚无结果。 |
| 未配置状态 | 请先配置朱雀文本检测。 | 告知无法开始检测的前置条件。 |
| 未配置动作 | 前往设置 | 完成首次配置。 |
| 请求状态 | 检测中… | 显示真实请求仍在运行。 |
| 本次范围 | 检测范围：全文正文 / 选区 | 防止把选区结果当成全文结果。 |
| 三类占比 | 人工、AI、疑似 AI 与百分比 | 保留厂商分类口径，不构造综合质量分。 |
| 装饰开关 | 正文标记 | 控制正文提示的可见性。 |
| 结果列表标题 | 待复核内容（数量） | 组织需要作者检查的片段。 |
| 结果分类 | AI 生成 / 疑似 AI，辅以不同符号 | 提供不依赖颜色的类别识别。 |
| 结果摘要 | 当前快照的短片段 | 帮助辨认并定位相应正文。 |
| 时间与扣减 | 本次扣减、检测时间，缓存命中或未知用量按实际显示 | 识别结果新鲜度和本次实际观测消耗。 |
| 复检动作 | 重新检测 | 对修改后的快照重新检测，强制请求应明确其会额外消耗额度。 |
| 失效状态 | 正文已修改，请重新检测。 | 防止对新正文使用旧占比或位置。 |
| 结果边界 | 检测结果仅供参考。 | 避免把统计推断当成作者身份或平台审核结果。 |
| 设置导航与标题 | 文章审查 | 与已有模型、MCP、同步设置并列。 |
| 服务开关 | 朱雀文本检测 | 启用或停用可选服务。 |
| 发送说明 | 仅主动检测时将正文或选区发送给腾讯。结果仅供参考。 | 在首次发送前明确接收方和发送时机。 |
| 凭据字段 | API Key、已配置 / 未配置、输入新密钥以替换 | 配置凭据而不回显已存密钥。 |
| 凭据删除 | 删除 | 移除本机系统凭据中的 Key。 |
| 配置动作 | 保存设置 | 明确提交本次启用和凭据修改。 |
| 验证动作 | 测试连接 | 使用固定非私人样本验证调用。 |
| 验证扣减说明 | 连接测试发送固定样本，会消耗检测额度。 | 在调用前说明测试同样消耗额度。 |
| 用量区域 | 本机用量、已观测扣减、成功调用、用量未知、缓存命中 | 区分设备观测记录与真实账户余额。 |
| 缓存区域 | 结果缓存、保留 30 天，仅此工作区可用。 | 说明已有结果的本机复用范围。 |
| 缓存清理动作 | 清理缓存 | 删除派生结果，保留用量统计。 |

原有工作区导航、标签、正文、状态栏和其他右栏图标仅用作上下文，不属于新增产品元素。原型顶栏的状态选择、明暗切换和模拟数据说明只服务原型预览，不进入产品。

## 生产交互约定

生产实现使用 Milkdown 独立装饰插件，不采用原型中的 contenteditable 或 DOM 标记。无有效选区时禁用选区检测；结果返回须核对工作区、文章、编辑器会话、文档代次及请求身份。未知位置不允许跳转，结果过期时撤下旧汇总和定位。普通复检优先使用缓存；强制重新请求另行明确额度影响。设置内的用量以 UTC 月统计，标明本机观测，不展示账户剩余额度。

## 原型检查

已在本机 Edge 检查审查面板、设置、浅色/深色和过期状态。原型模拟请求的延迟只用于演示，不作为生产请求状态的计时依据。实际产品测试与性能记录见 `../article-quality-review-results.md`。
