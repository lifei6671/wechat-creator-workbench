# 公众号配置验收记录

实现范围为已确认的公众号侧栏、推荐阅读、文章选择器、同步和远端备份。固定头部与固定尾部不在本次范围。

## 可见元素与用途

| 区域或文案 | 用户用途 |
| --- | --- |
| 工具栏「公众号」、侧栏标题和关闭按钮 | 进入或离开当前文章的公众号配置 |
| 「当前文章」「默认设置」 | 区分文章配置与跨文章共享的默认数量 |
| 「排版主题」 | 选择公众号输出样式 |
| 「推荐阅读」开关 | 控制本次输出是否附加推荐，保留已有选择 |
| 「生成数量」「篇」「默认」「使用默认」 | 调整自动生成的数量，或继承共享默认值 |
| 「自动推荐」「手动调整」 | 识别当前列表是否保留人工选择 |
| 推荐文章标题、排序手柄及操作菜单 | 阅读选择结果并调整顺序 |
| 「上移」「下移」「移除推荐」 | 通过菜单完成排序与删除，提供拖动以外的操作路径 |
| 「重新推荐」「撤销」 | 替换当前推荐，或恢复上一列表 |
| 「添加文章」 | 打开往期文章选择器 |
| 「尚未添加推荐文章」「没有找到相关文章」 | 识别列表为空或当前搜索没有结果 |
| 「默认生成数量」及适用范围说明 | 设置未单独覆盖数量的文章所使用的默认值 |
| 「重新加载」 | 保存遇到版本冲突后重新读取共享配置 |
| 「复制公众号格式」及按钮内处理结果 | 复制当前公众号输出，反馈真实完成状态 |
| 选择器搜索、相关推荐、全部文章 | 筛选有微信发布链接的已发布文章 |
| 选择框、摘要、标签和发布日期 | 判断候选文章并批量选择 |
| 「已添加」 | 识别列表中已有文章，避免重复选择 |
| 「添加 N 篇」「取消」及关闭按钮 | 确认所选文章或离开选择器 |
| 列表错误、固定错误区域及预览错误 | 修正失效推荐、无效数量或保存失败 |
| 同步设置中的公众号默认设置冲突、本地/云端数量和版本选择 | 在两台设备并发修改时明确保留哪一版 |
| 输出尾部「推荐阅读：」和文章链接 | 为公众号读者提供相关文章入口 |

## 验证边界

- 本地推荐：具体主题排序、通用标签不补齐无关结果、非微信候选与正文已有链接不挤占排序、现代平台空链接不回退旧链接。
- 保存：人工删空与超过 5 篇、排序、重新推荐和撤销、过时异步结果、排队重新推荐与人工修改竞争、输入及写入失败、备份前保存屏障。
- 渲染：全部 9 套主题，预览与复制附加一次、普通 HTML 不附加、标题按文本处理、长微信链接参数完整、原始 Markdown 保持不变。
- 同步：协议 2 及旧客户端拒绝、共享单例、文章配置与人工空数组、非法输入、并发版本冲突、首次加入、完整对账、Local/Cloud 处理、基线替换及刷新。
- 备份：数据库 Online Backup 保留未 checkpoint 的 WAL；真实 R2 隔离前缀上传、分页、保留策略、下载字节比较及配置恢复，恢复后同步暂停。
- 原生 HTTP：隔离回环服务与系统凭据存储下的双设备同步、重装恢复、推荐模式/数量/顺序/完整链接、另一设备删空及公共配置回传。

真实 R2 备份测试只创建并清理自身唯一测试前缀，没有修改生产文章或现有备份对象。

## 生产协议升级验收

2026-11-22，在现有生产 Worker 上部署协议 2，沿用原 D1、R2、服务地址、实例 ID、同步世代和密钥，不重新认领工作区，不创建或轮换设备凭据。部署前完成 D1 全量 SQL 导出，并在本地隔离 SQLite 中恢复核对。备份保存在应用数据目录下的 `deployment-backups`，不纳入 Git。

- 升级前后 406 个既有实体全部保留，版本没有倒退；347 条 blob 记录不变。设备记录与凭据摘要逐项一致。
- 新版元数据返回协议 2，实例、世代、已认领及 ready 状态保持一致。旧协议请求返回 426，新协议缺少凭据时仍返回 401。
- 原桌面端使用原设备连接自动恢复同步，再执行一次「立即同步」，界面显示「已同步」。本地与远端游标从 585 推进到 586，dirty、outbox、inbox 和 issues 均为 0。
- 当前文章的公众号配置与远端载荷逐项一致。文章正文、标题、来源及原发布链接未改变；同步补入公众号配置及等价的空平台数组，并更新修改时间。
- 原私有 R2 对象抽样下载成功，2,552,322 字节文件的 SHA-256 与其对象键一致。部署没有替换或清理现有存储。

完整 HTTP 契约中会初始化空服务的场景继续使用隔离目标，未在既有生产工作区运行。

Windows 执行本地构建及运行检查；Chromium 和 Windows WebKit 验证浏览器交互。macOS 原生构建、系统剪贴板粘贴到真实公众号后台，以及另一台物理设备在生产升级后的原生运行未验证。
