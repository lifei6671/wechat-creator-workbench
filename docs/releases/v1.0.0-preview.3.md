# 微信创作工作台 1.0.0-preview.3

本次预览版新增文章文本检测、审查历史和异常退出恢复，改进 Markdown 编辑、公众号排版、素材保留及同步恢复。提供 Windows x64、Mac Intel、Mac Apple 芯片安装包，以及 Cloudflare 与 VPS/NAS 同步服务包。

## 编辑与公众号排版

- 支持直接编辑 Markdown 语法，改善源码编辑与所见即所得编辑之间的切换，修复阅读模式切换后撤销历史丢失的问题。
- 图片导入和上传保留原始动图数据，改善远程图片本地化、失焦后继续编辑及图片居中显示。
- 统一编辑区与阅读预览中的正文、标题、列表、引用和代码排版，新增莫兰迪公众号主题，恢复编辑时的主题呈现。
- 改善主题宽度、长图显示、图片说明及复制到公众号的富文本排版，并修复源码编辑区域宽度异常。

## 文本检测与审查历史

- 新增可选的腾讯朱雀文本检测，支持检测全文或选区，查看分类比例、定位相关片段，并在修改后重新检测。
- 检测默认关闭，需要在设置中配置自己的 API Key。仅主动检测时将所选正文发送给腾讯，连接测试也会消耗检测额度；结果仅供参考。
- 当前文章可查看、删除或清空自己的审查历史。同一文本可复用本地缓存，切换文章后不会混入其他文章的记录。
- API Key 保存在系统凭据库中，检测缓存和审查历史保留在本地，不加入文章同步、备份或公众号导出。
- 时间流显示文章状态，便于识别草稿、待发布及已发布等内容。

## 正文恢复与素材保留

- 为正在编辑的正文保存本地恢复草稿，异常退出后可比较并恢复；遇到正式内容变化时保留恢复稿，不自动覆盖新版本。
- 修复恢复草稿与已有来源链接冲突时无法继续保存的问题。
- 素材清理增加本地保留与引用保护，减少历史版本、恢复草稿及备份仍需使用的图片被过早清理的情况。
- 备份恢复后支持检查素材可用性，定位缺失或校验失败的图片；数据库备份仍不等于包含全部图片的完整工作区导出。

## 同步与网络

- 对齐同步服务与桌面客户端的实体校验，增加异常数据和附件诊断，改善首次初始化受阻、基线下载失败及多层依赖恢复。
- 修复相关内容后，目录重名、来源链接重复等可修复拒绝能够以原子分组重新提交；版本冲突仍通过现有冲突处理入口解决。
- 外部图片使用系统 DNS，兼容本机 TUN 代理的 Fake IP 解析模式，并保留对真实内网目标的访问限制。
- 改善设置行对齐、错误反馈、对话框切换和跨平台字体显示。

## 升级与安装

- 升级前保留工作区备份。打开已有工作区时会执行数据库迁移；恢复稿和素材保护所需的数据结构由应用自动建立。
- 使用自托管同步时，同时升级对应的 Cloudflare 或 VPS/NAS 服务端包，以获得本次校验、诊断和恢复改进。按包内 README 操作，保留数据库、素材、配置及持久化卷；桌面安装包不会自动升级服务端。
- 本版本为预览版，不进入正式版自动更新通道，请从本次 Release 页面手动下载安装。macOS 安装包采用 ad-hoc 签名，未经 Apple 公证；首次打开可能需要在系统“隐私与安全性”中允许打开。
