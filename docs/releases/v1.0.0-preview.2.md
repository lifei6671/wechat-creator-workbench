# 微信创作工作台 1.0.0-preview.2

本次预览版改进中文搜索、MCP 连接、公众号推荐阅读及编辑交互，并修复标题栏错位和长网址排版问题。提供 Windows x64、Mac Intel、Mac Apple 芯片安装包，以及 Cloudflare 与 VPS/NAS 同步服务包。

## 搜索与 MCP

- 中文全文搜索接入分词与相关性排序，保留原句、局部字符串、字段限定和原文定位能力。
- 搜索索引在后台分批重建，完成后切换到新索引，减少重建期间对写作和检索的影响。
- MCP 设置提供客户端连接配置、连接状态和搜索片段，方便从支持 MCP 的工具访问工作区。

## 公众号排版与推荐阅读

- 推荐阅读支持同步默认数量和多个作者筛选条件，并可为当前文章单独配置。
- 修复显式点击自动推荐后继续编辑正文或标题，返回过期结果却显示推荐成功的问题；推荐请求会按最新输入重新计算。
- 移除已选作者时保留尚未提交的输入，避免筛选条件意外清空。
- 长网址接着中文标签或参考资料编号排版，剩余部分自然折行；普通英文单词与代码保留原有断行方式。
- 修复公众号列表中加粗标签与后续说明被拆成两行的问题。

## 编辑与窗口交互

- 修复标题栏预留空间异常膨胀，造成文章标签页消失、右侧栏开关移到左侧的问题。
- 顶部菜单、列表空白区及文件夹右键菜单新建文章后，焦点留在正文，避免菜单退出时抢走输入焦点。
- 修复侧栏折叠图标在最大化等状态下只剩一条线的问题，统一侧栏、标签页、菜单及操作反馈的过渡，并遵循系统减少动态效果设置。
- 代码围栏转换仅处理本次编辑实际补全的围栏，避免普通输入误改已有转义反引号、拆分段落或移动光标。
- 改善图片上传恢复、保存状态、目录导航反馈及窗口缩放时的侧栏稳定性。

## 升级与同步服务

- 已有工作区会在打开时按当前数据库版本迁移；升级前建议保留工作区备份。
- 使用自托管同步的用户应同时升级对应服务端包，以同步推荐阅读默认设置；保留现有数据库、素材、配置和持久化卷，按包内 README 操作。
- 桌面安装包不会自动部署或升级同步服务端。
- 本版本为预览版，不进入正式版自动更新通道，请从本次 Release 页面手动下载安装。
