# 微信创作工作台 1.0.0-preview.1

首个公开预览版，提供 Windows x64、Mac Intel 和 Mac Apple 芯片安装包。

## 收集与写作

- 导入公开公众号文章、网页、GitHub 仓库 README 和本地 Markdown，保留来源，使用文件夹、标签和全文搜索管理资料。
- 在选题画布中组织文章、图片和文本卡片，通过连线与批注整理思路。
- 使用可视化编辑器编辑 Markdown，支持大纲、多标签页、表格、代码块、公式和 Mermaid 图表，提供自动保存、历史版本和回收站。
- 按需接入 Codex CLI、Claude Code、本地模型或自定义 AI 接口，辅助总结、生成标题和修改正文；提供本机 MCP 服务。

## 公众号排版与图片

- 选择公众号排版主题，在手机尺寸预览中检查效果，复制公众号格式，或导出 Markdown 与 HTML。
- 管理推荐阅读文章，支持手动添加、拖动排序和键盘排序；拖动时原条目随鼠标移动并预留落点。
- 启用 S3 兼容图床并设为默认图片存储后，导入和粘贴的图片先保存到本地素材库，再异步上传并替换正文链接，上传期间显示进度。
- 图片公开地址校验、链接替换与正文保存全部完成后再结束保存状态，减少保存提示反复切换；临时校验失败后允许再次检查。
- 修复推荐阅读手动添加时携带多余字段导致保存失败，以及同一保存错误在多个位置重复显示的问题。
- 改善输入时标题栏与复制按钮的反馈稳定性，以及侧边栏拖动和窗口缩放表现。

## 本地数据与同步

- 文稿与素材默认保存在本机，支持离线写作、工作区迁移和 S3 数据库快照。
- 随版提供 Cloudflare 与 VPS/NAS 自托管同步服务包，支持多设备同步和冲突处理。部署方式与数据保留要求见各包内 README。
- 已有源码运行用户可继续使用原工作区；桌面安装包不会自动部署或升级同步服务端。

## 更新方式

本版本为预览版，请从本次 Release 页面手动下载安装。应用内更新入口只检查正式版本，后续预览版仍需手动安装。
