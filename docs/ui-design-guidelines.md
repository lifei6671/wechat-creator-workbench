# 微信创作工作台桌面界面与交互设计规范

> 版本：1.3
>
> 适用：wechat-creator-workbench 的 Windows 11 / macOS 桌面界面  
> 技术基线：Tauri 2 + React + TypeScript + Radix UI Themes + Milkdown
> 相关文档：[MVP 技术方案](./mvp-technical-design.md)、[实施计划](./implementation-plan.md)

## 1. 设计目标

本应用面向微信公众号创作者，主要任务是**快速收集灵感、整理参考资料、持续写作、排版并复制到公众号后台**。

交互方向：借鉴 Obsidian / VS Code 的信息密度、导航效率和桌面操作习惯；借鉴专注写作工具的低干扰编辑体验。主要界面是连续工作区，不是网站后台、卡片看板或仪表盘。

默认使用**紧凑工作台模式**；提供一键进入**专注写作模式**。这是同一套工作区的两种布局状态，不是两套独立 UI。

设计优先级：
1. 文章正文和公众号预览占据主要屏幕面积。
2. 笔记可按目录组织并在同一搜索入口检索。
3. 编辑、保存、图片插入与发布动作始终明确；键盘和鼠标同等可用。
4. 桌面窗口、菜单、快捷键、拖放、剪贴板符合操作系统使用习惯。
5. Radix UI Themes 提供视觉基础，产品布局与操作组件形成自己的统一语言。

## 2. 组件选型与职责

| 技术 | 使用范围 | 约束 |
| --- | --- | --- |
| Radix UI Themes | 按钮、输入框、选择器、弹窗、菜单、提示、设置页表单 | 优先利用官方 props / 主题令牌，不大面积覆盖组件内部选择器 |
| Radix UI Primitives（按需） | Themes 难以覆盖的无障碍交互基础 | 同类控件优先选一种实现，避免叠加多个组件系统 |
| Lucide React | 统一线性图标 | 常规 16px、辅助 14px、空状态 24px，不混用多套图标风格 |
| react-resizable-panels 4.x | 工作区侧栏宽度调整 | 使用 Group / Panel / Separator API；侧栏宽度持久化到界面设置 |
| Milkdown / ProseMirror | 富文本编辑、选区、快捷键、撤销与 Markdown 转换 | 正文按排版直接编辑，Markdown 用于持久化和发布 |
| Plainly 抽离模块 | 公众号排版、主题、代码块与富文本输出 | 公众号预览使用独立样式作用域，不继承工作台的组件样式 |
| 自定义 React 组件 | 目录树、标签栏、状态栏、命令面板外壳、预览容器 | 只抽象至少在多个场景复用的逻辑，不为了设计体系建立庞大组件库 |
| Tauri 2 | 原生窗口、文件对话框、剪贴板、系统主题、菜单 | 原生能力由专门适配层调用，组件不直接散落系统 API |

**明确不采用**：基于大面积 Card 的后台仪表盘布局、多个彼此不兼容的主题系统、与工作流无关的视觉动画、为外观统一而重写可用的 Radix 基础控件。

Radix UI Themes 本身提供完整视觉样式；主工作区的导航、分栏、标签页与状态栏以项目 CSS 和设计变量实现，不强行使用 Radix Card 拼装。

## 3. 工作区信息架构

### 3.1 页面结构

~~~text
┌────────────────────┬─────────────────────────────────────────────────┐
│ 导航 / 新建 / 收起 │ 标签页 / 新建内容              最小化 / 最大化 / 关闭 │
│                    │ 内容路径                  分享 / 阅读 / 更多      │
│                    │                                                 │
│ 文件夹             │ 富文本编辑器               可选的公众号预览        │
│   子文件夹         │                                                 │
│   内容             │                                                 │
│ 根目录内容         │                                                 │
├────────────────────┴─────────────────────────────────────────────────┤
│ 命令面板 / 回收站     保存状态 / 字数 / 预览排版 / 复制公众号格式 / AI 助手 / 设置 │
└──────────────────────────────────────────────────────────────────────┘
~~~

说明：右侧 AI 聊天默认折叠，通过编辑区右上角的按钮展开或收起。展开后独占一列，主工作区让出相应宽度。文章属性和关联资料按需打开。公众号预览使用主工作区。

### 3.2 推荐尺寸（CSS 像素，作为初始实现令牌）

| 区域 | 默认尺寸 | 行为 |
| --- | --- | --- |
| 窗口 | 1360 × 840 | 最小尺寸建议 1000 × 640；支持最大化及窗口记忆 |
| 资源导航区 | 默认 337px 宽 | 各视图共用总宽度。可拖动，也可隐藏 |
| 顶部标题与标签栏 | 40px 高 | 导航图标、横向标签、新建菜单、窗口控制共用一行 |
| 编辑区工具行 | 42px 高 | 路径、分享菜单、阅读模式与更多操作 |
| 编辑区与预览区 | 共用正文区域 | 使用同一入口切换，切换时保留编辑内容 |
| AI 聊天 | 默认 350px，最小 300px，最大为窗口可用宽度的一半 | 独立列，可调宽度，使用与目录栏一致的折叠交互 |
| 底部状态栏 | 32px 高 | 贯穿窗口，左侧是命令面板和回收站，右侧是文稿状态和常用操作 |

首次打开时使用通用设置中的默认视图与资源导航状态。再次启动时恢复上次的工作区视图、侧栏布局、目录与标签的展开状态、文章时间流筛选和分组折叠状态，以及打开的标签页和各标签页的阅读、预览与大纲可见性。状态栏切换当前文档的编辑或公众号排版预览。窗口过窄时优先折叠资源导航区和辅助面板，给正文保留可用宽度。

标签关闭时以 250ms ease-out 收缩并淡出，包含「关闭其他标签页」中的批量关闭。已关闭标签只保留不可交互的短暂视觉副本，保存及关闭结果不等待动画。遵循系统的减少动态效果偏好。Windows 窗口按钮区使用不透明的标题栏背景，侧栏展开和收起时内容不得透出。

大纲以浮层覆盖正文，不给编辑区预留宽度，也不改变正文和查找栏的布局。

### 3.3 编辑、预览与阅读

- **编辑**（默认）：编辑区居中，正文最佳阅读宽度约 720–840px。
- **排版预览**：以公众号实际呈现宽度展示主题内容，外围保留简洁的工具栏。
- **阅读模式**：当前标签页显示工作区排版，标题和正文只读。相同按钮退出阅读模式并恢复原视图。

**专注写作**：暂时折叠资源导航和属性/AI 面板。底栏显示保存状态、字数和退出专注写作入口。退出专注后恢复侧栏宽度及布局偏好。

## 4. 视觉系统

### 4.1 Radix 主题起点

- Theme 外观跟随系统浅色/深色；用户可以在设置中覆盖为浅色或深色。
- accentColor：indigo（靛蓝）；grayColor：slate（冷灰）；radius：small；scaling：95%；panelBackground：solid。
- 默认采用中性冷灰底色，强调色只用于选中、聚焦、主要动作及交互反馈；大面积编辑区域保持低干扰。
- 工作区控件跟随界面主题。公众号文章主题即时更新正文排版，也用于预览和发布输出。
- 所有工作区颜色使用项目语义变量映射 Radix 令牌，避免在各组件中直接写死颜色值。

~~~tsx
import { Theme } from "@radix-ui/themes";

<Theme
  appearance={resolvedAppearance} // 映射 Tauri 系统主题或用户选择，值为 light/dark
  accentColor="indigo"
  grayColor="slate"
  panelBackground="solid"
  radius="small"
  scaling="95%"
>
  <DesktopWorkspace />
</Theme>;
~~~

Radix 的 Theme 支持 appearance、accentColor、grayColor、panelBackground、radius、scaling 等属性；具体支持值见官方文档。这里的 95% 是初始密度选择，不代表应强制缩小正文编辑字体。

### 4.2 语义颜色变量

工作区定义语义变量，引用 Radix 颜色令牌：

~~~css
.workspace-shell {
  --app-bg: var(--gray-1);
  --sidebar-bg: var(--gray-2);
  --panel-bg: var(--gray-1);
  --panel-hover: var(--gray-3);
  --panel-selected: var(--accent-3);
  --divider-color: var(--gray-a6);
  --text-main: var(--gray-12);
  --text-muted: var(--gray-10);
  --focus-color: var(--accent-9);
}
~~~

规则：背景层级最多 3 级（窗口/侧栏/编辑区）；区域主要靠分割线、轻微背景差与内容对齐区分，不依赖阴影和大卡片。Light/Dark 两种模式均需要检查对比度。

### 4.3 字体、间距与图标

| 元素 | 默认建议 |
| --- | --- |
| 导航/列表正文 | 13–14px，行高约 1.4 |
| 工具栏/状态栏 | 12–13px |
| 编辑器正文 | 15–16px，行高 1.65–1.8，可调 |
| 设置页标题 | 16–18px，不使用营销式大标题 |
| 菜单项高度 | 32px，右键菜单、下拉菜单和子菜单共用行高与留白 |
| 文章列表行高 | 32–36px |
| 常规按钮高度 | 28–32px |
| 图标 | 16px 为主，控制区点击范围不小于约 30px |
| 布局间距 | 4 / 8 / 12 / 16 / 24px 五档 |
| 边框 | 0.5px，使用主题分割线颜色 |
| 常规圆角 | 4–6px；弹窗可适当增大 |
| 动画 | 优先直接切换，必要过渡使用 ease-out，约 250ms |

这些数值是设计起点，不是测试结论。Windows/macOS 字体渲染差异与用户缩放可能要求微调；编辑器正文的可读性优先于工具栏密度。

不要用纯黑背景配纯白正文作为默认深色主题；不要通过降低到 11px 甚至更小来制造信息密度。中英文混排需要检查字重、标点和字号。

## 5. 组件规范与交互规则

### 5.1 目录与内容导航

- 回收站标题栏右侧提供「清空回收站」图标按钮，空回收站和处理期间禁用；永久清理前确认。状态栏入口使用垃圾桶图标。「设置 → 通用」提供回收站保留时间，默认 7 天，可选 1、7、14、30、90 天或不自动清理。自动清理在启动时及运行期间每小时检查，只处理超过保留期的已删除内容。

- 目录、全文搜索和素材使用标题左侧的横向图标入口，图标提供可访问名称和工具提示。导航和侧栏开关使用统一大小和线宽的图标及方形按钮。导航选中、侧栏开关悬停和 AI 侧栏展开时使用浅暖灰反馈。窄栏调整按钮和间距以容纳所有入口。回收站和设置位于全宽底部状态栏。点击回收站会打开侧栏并显示回收站。
- 同一图标区提供「导入的外部文章」入口，集中显示通过链接导入的内容。导入弹窗接受公开网页链接，保留微信公众号和 GitHub README 的专门解析，其他网页提取正文并转换为 Markdown。弹窗仅显示本次提交的状态和可用操作。
- 内容目录顶部的快捷栏提供新建笔记、新建目录、排序、自动定位当前文件和全部折叠与展开。全部折叠后，同一按钮切换为「全部展开」。再次点击已选中的「内容目录」将新建内容的位置设回根目录。
- 鼠标悬停时，工作台工具提示与控件的上下边缘留出约 8px 的间距，横向对齐弹出时的鼠标位置，出现后保持原位。键盘聚焦时锚定控件。
- 排序菜单支持文件名、编辑时间和创建时间的双向排序，以及文档手动排序。目录保持手动顺序，可独立调整。「置顶」和「目录」使用同样的标题样式，悬停或键盘聚焦时显示折叠箭头。两区可独立折叠并记忆状态，动画遵循减少动态效果偏好。置顶区内可拖动排序，取消置顶后文档出现在原目录。
- 笔记共用两级目录树。没有分配文件夹的笔记位于根目录。展开文件夹时显示直属笔记和子文件夹，展开状态记忆到本地界面偏好。
- 工作区预置「文章」「灵感」「资料」三个根目录，可按普通目录重命名、排序或删除。
- 文件夹加载时在原图标位置显示进度。通用设置可切换一次性加载或滚动分页，并设置每页笔记数。
- 目录内直接新建或重命名。新建行位于当前层级末尾，图标和名称共用一行。回车或离开该行保存，Esc 取消。图标按钮打开 Lucide 图标浮层，选中的图标同时显示底色和勾选状态。
- 专题侧栏沿用内容目录的快捷栏、折叠分组和列表选中样式。新建专题在左侧列表末尾输入名称，保存后保留该位置。重命名在原行输入。回车或离开该行保存，Esc 取消。右键专题行可重命名或删除。文章右键的「加入专题」可将文章作为引用卡片加入所选画布。
- 标签栏「+」和目录留白的右键菜单提供新建笔记、导入链接和导入 Markdown。内容目录的留白菜单还可以在根目录新建目录。文章时间流中，选中目录后才可在中间栏的空白处打开菜单。新建和导入的笔记进入所选目录，选中一级目录时可在其中新建子目录。
- 删除空目录直接执行。删除非空目录时，默认将直属文档及子目录上移一级，子目录内的文档保持原归属；上移后遇到同名目录时加编号保留两者。勾选「同时删除所有子文件夹和文档」后，删除全部子目录并将文档移入回收站。
- 文件夹菜单提供新建笔记、导入链接、导入 Markdown、目录管理与排序。点击文档时按通用设置选用当前标签或新标签，右键菜单提供另一种打开方式。文档列表右键菜单首项为「置顶」或「取消置顶」。「移动到文件夹」子菜单标记当前位置。子目录紧随父目录排列，仅显示本级名称，通过缩进表示层级。也可从内容属性移动文档。右键菜单打开时描出被操作的目录或笔记。
- 搜索使用单行输入框和大小写开关。搜索框聚焦或点击「搜索语法」时可查看命令和最近搜索。选用命令后光标落在括号内。支持 `path:`、`file:`、`content:`、`tag:`、`line:`、`section:` 和属性查询。用双引号匹配短语，用括号组合多个词。
- 搜索框右侧的设置按钮在下方展开「折叠搜索结果」「显示更多上下文」「说明搜索含义」三个开关。说明区在搜索框下用缩进展示匹配范围、组合条件和具体文本。结果按笔记分组，可按相关性、标题、修改时间或创建时间排序。展开后显示命中行、行号及高亮词。开启上下文时，命中行显示完整的 Markdown 原文和匹配高亮，并附上相邻行的片段。关闭时恢复命中行的短片段。点击命中行在正文定位并高亮，笔记标题和属性查询结果可直接打开文档。
- 内容目录和文章时间流的目录行保持单行、常规字重，悬停目录行时不弹出名称提示。文档行悬停时在右侧显示完整标题、创建时间和更新时间，长标题可换行。目录层级缩进作用在文字和图标上，行背景按同样的宽度显示，两侧留白相同。内容目录中的目录行用于展开和折叠，文档行显示选中状态。侧栏展开和隐藏使用 200ms 缓动，并遵循系统的减少动态效果偏好。
- 内容的右键菜单包含副本、移动、重命名、复制标题和目录路径、历史版本、导出及回收站操作。内容目录和文章时间流的文章菜单末项为「内容属性」，直接打开被点击文章的属性。重命名在原行编辑，回车或离开该行保存，Esc 取消。
- 目录可拖动排序。文档在手动排序模式下可在同一目录内拖动调整顺序，显示插入线并记住顺序。所有排序模式下都可把文档拖入其他目录，拖到目录栏空白处可移回根目录。跨目录时高亮目标目录。
- 素材库按侧栏宽度自动分列，缩略图按图片比例排列成瀑布流，超长图在缩略图内完整显示。图片加载前即预留版位，列数不变时保持列归属。标题旁的图标切换缩略图大小并记住偏好。每页 48 张，以左右箭头翻页。滚到可见区域时加载缩略图，选中后查看大图和存储状态。翻页时保留已选素材的预览和操作，选中其他素材后再切换。素材变更时，跨页保留的选中项按 ID 独立刷新存储状态、图床链接及重试操作，上传状态更新不重新加载已有本地预览。直接导入素材库的图片在退出后保留。
- 「文章时间流」在左侧显示目录树，中间按最近编辑时间倒序分组显示文章，右侧使用现有标签页阅读和编辑。目录与时间流共用连续的顶部标题栏，隐藏按钮位于共用标题栏最右侧，紧邻编辑区，控制两栏一起隐藏或恢复。目录栏和文章栏的宽度分别记忆。左侧分隔线调整目录栏，文章栏宽度不变。右侧分隔线调整两栏总宽度，文章栏至少 416px。拖动中若总宽度容不下两栏，目录栏即时收起，文章栏接管这部分空间。拖回足够宽度时，自动收起的目录栏按原宽度即时展开。手动收起的目录栏通过展开按钮恢复。手动收起和展开使用 200ms 缓动，并遵循系统的减少动态效果偏好。收起后，展开按钮位于文章栏标题行的目录或标签图标前。两栏都显示时，折叠按钮位于目录快捷操作区的最右侧，靠近分隔线。导航文字不参与拖选，行内重命名仍可选择文字。目录列表第一项为「根目录」，只显示未归入任何目录的文章。初次进入时间流时默认选中根目录，并显示其中的文章。点击目录行只选中该目录。点击行首箭头可展开或折叠其子目录，动画遵循减少动态效果偏好。「标签」区与上方目录留出间距，标签项按子目录的层级缩进。该区可折叠，可按标签或「无标签」筛选文章。目录和标签行右侧显示对应文章数，目录计数遵循「包含子目录」设置。中栏默认包含所选目录的子目录文章，可以按需切换。「包含子目录」按钮与文章列表的滚动条留出横向间距。文章行显示标题、摘要、标签、时间和可用的配图。点击文章标签会切换到该标签的列表，并同步选中左侧标签。悬停或聚焦文章行时显示置顶按钮，并复用内容目录的文章菜单。固定文章只在顶部「已固定」分组显示，取消置顶后回到日期组。各分组的标题在滚动时吸顶，点击可折叠或展开。
- 文章时间流中的置顶按当前选择保存，根目录、各个目录、各个标签和「无标签」各有自己的「已固定」列表。包含子目录时，置顶属于当前选中的目录。内容目录视图的「置顶」单独保存。
- 每种列表设置统一的 hover、selected、focus-visible、disabled 状态，选中不能只依赖颜色变化。

### 5.2 标签页与编辑器

重启后恢复上次已打开的文稿标签顺序和当前文稿，并保留目录展开或折叠的状态。

- 每篇文章对应一个标签，重复打开时定位到已有标签。「在当前标签打开」先保存当前标签页的稿件，再在原位置打开文章。「在新标签打开」追加标签。
- 打开的专题与文章共用顶部标签栏，能直接切换和关闭，重启时恢复已打开的专题。右键画布空白处可添加内容，右键卡片或连线可执行对应的操作。
- 专题标题显示在标签栏。文本和文章卡片按 Markdown 排版展示正文，文章和图片卡片在上沿标注名称。左键可从卡片任意非编辑区域拖动，靠近其他卡片的边缘或中心时显示对齐线并吸附。双击文本或文章可在卡片内编辑，双击图片可调整尺寸。按住鼠标右键拖动可平移画布，连线使用贝塞尔曲线。
- 单选卡片时在上方显示删除、边框颜色和聚焦工具。文本和文章卡片另有编辑工具。图片卡片显示原图，边框贴合原始宽高比，调整尺寸时保持比例。
- 粘贴单个网址时，网页卡片直接显示网页。网页标题沿用其他卡片的上沿标注，加载标题前显示域名。预览占据卡片内部，系统浏览器入口放在卡片工具条与右键菜单。
- macOS 专题画布支持触控板双指滑动平移、双指捏合缩放，按住 ⌘ 滚动也可缩放。Windows 保留滚轮缩放。缩放以指针位置为中心，缩放按钮和聚焦使用约 250ms ease-out 过渡，并尊重系统减少动态效果设置。卡片编辑区的滚动由编辑器处理。
- 操作工具条、在卡片内编辑或将键盘焦点移到其他控件时，单选卡片继续保持选中。单击另一张卡片可切换选中项。左键单击画布空白处退出选中并隐藏工具条。
- 工具条使用紧凑的图标按钮。设置颜色打开横排色板，预设色与自定义色同时应用到卡片边框和淡背景。选中时加粗原有边框，取消选中时恢复原粗细。连线悬停时平滑加粗，跟随系统的减少动态效果设置。
- 文本和文章卡片离开编辑区时保存。画布右键菜单的每项操作均配图标。编辑时使用当前正文的右键菜单，菜单、插入链接和脚注等局部操作保留编辑焦点。
- 窗口顶部标题栏和底部状态栏使用同一组 Radix Sand 暖灰背景。当前标签使用正文区或专题画布的背景色，上沿保留圆角，下沿与内容区直接相接。标签使用常规字重。
- 标签栏支持鼠标切换、关闭、中键关闭（Windows 平台按常见习惯）、键盘导航；关闭前先处理正在进行的保存。
- AI 侧栏展开、折叠或改变宽度时，激活标签完整保留在可视区。标签栏溢出时，最后一个激活标签贴住滚动区右边缘，向左和向右滚动按钮分别位于列表两端；两侧保留固定占位，按钮显隐不挤动标签。
- AI 侧栏展开和收起使用 250ms ease-out 宽度过渡，过渡标记保持到动画结束；系统启用减少动态效果时直接切换。
- 标签可拖动排序，拖动时显示跟随鼠标的缩略图和插入线。对应方向还有标签时才显示箭头，也可在标签区域用鼠标滚轮平滑滚动。
- 标签页右键提供关闭、阅读、查找、属性、历史版本、移动、导出等当前内容操作。面包屑最后一项获得焦点后可编辑标题，回车或失焦保存，Esc 取消。
- 底栏左侧放命令面板和回收站，右侧放当前文稿的保存状态、字数、预览排版和复制公众号格式，最右放 AI 助手和设置。未打开文稿时显示工作区入口；窄窗口将命令面板缩为图标，保留可访问名称和快捷键提示。
- 状态栏区分「未保存」「保存中」「已保存」「保存失败」。保存失败时在编辑区下缘提供错误详情和恢复操作。
- 当前文档的图床上传以图标和已上传数/总数显示在状态栏。备份和工作区迁移显示当前阶段。状态栏左侧的 MCP 图标和文字在运行时为绿色，停止时为红色，点击打开 MCP 设置。
- 图片粘贴和异步插入绑定当前文章和插入位置。读取剪贴板期间在原插入位置显示粘贴占位和进度动画，加载图片时继续显示图片状态。完成或失败后收起占位。
- 正常粘贴会将 Markdown 文本或单个 UTF-8 Markdown 文件转换为编辑器排版。剪贴板的 HTML 副本如果仅给 Markdown 源码添加语法样式，按 Markdown 正文处理。真实富文本保留格式，纯文本粘贴保留字面内容。
- 用「导入 Markdown」打开文件时，首行的非空 `#` 一级标题成为文档标题，其余内容进入正文。没有符合条件的首行时使用文件名。
- 正文可直接预览公开的外链图片。普通外链按 HTTP 缓存规则保存到应用缓存目录，重新打开时可复用，正文保留原 URL。通用设置可在粘贴或导入普通网页及 GitHub README 时将外链图片自动保存到本地素材库。下载失败及已配置 S3 图床的图片保留原链接。
- 目录内容区与设置弹窗使用 Radix Sand 暖灰背景。S3 图床通过复选框启停，测试和保存成功仅在对应按钮内反馈；失败原因显示在按钮左侧预留区域。密钥从系统凭据存储回填，秘密访问密钥默认遮挡。「默认存储到图床」默认关闭，开启后，导入、粘贴或拖入的图片会自动排队上传；新插入编辑器的图片先用本地地址显示，上传及公开地址校验成功后在原位置替换为图床链接。失败保留本地图片并显示错误，上传期间删除或修改图片后不覆盖用户操作。粘贴仍可整体撤销，本地原图保留用于预览和导出。
- 启用 S3 图床后，图片右键可上传单张，「更多编辑操作」提供「批量上传到图床」。上传中的图片在左上角显示进度动画，右键菜单显示「正在上传」并禁用重复上传。公开链接校验成功后更新正文，整篇替换可以一次撤销。
- 图床命名规则提供年月日时分秒与毫秒时间戳变量和文件名预览。高清、标清和省流在本地生成 WebP 上传副本，文件名预览随所选清晰度更新。原图、GIF 和动态 WebP 保持原始字节。
- 新建内容直接进入单栏编辑。文内查找与替换在编辑区右上角浮动，显示当前匹配序号和总数，定位时滚动正文，让匹配出现在浮层下方的可见区域。同一文稿关闭并重新打开查找时保留查询、替换内容和匹配选项。
- 正文图片悬停、选中或获得键盘焦点时显示不透明的紧凑浮层，选中或获得焦点时图片边缘显示加粗描边和轻阴影。放大在当前窗口的遮罩上显示图片，可点遮罩、关闭按钮或按 Esc 返回。源码在当前图片上方编辑，有效修改随回车或失焦保存并收起。无效的图片或公式源码在失焦后保留草稿并显示错误，可继续修改或按 Esc 放弃。图片使用专属右键菜单，可复制、另存为或从正文移除。加载失败时在对应图片的占位处提供重试。阅读模式可放大、复制和另存为。
- 正文用标题、粗体、列表等样式直接编辑。右键菜单提供文本格式、段落设置、插入链接、脚注、表格、分隔线、代码块和数学块，以及系统剪贴板操作。段落设置和插入命令均可选择一至六级标题。
- 在正文单独一段开头输入 `/` 可打开按分组排列的插入命令，继续输入可按中文或英文筛选。用上下方向键选择、回车执行、Esc 关闭。悬停普通区块时，左边的加号在下方打开同一菜单，拖动手柄可移动整个区块，包括表格。每一级列表项都可在所属列表内拖动排序，子列表随父项移动。拖动时可用滚轮滚动正文，落点线随滚动更新，按 Esc 可取消拖动。标题悬停时，折叠箭头旁仅显示拖动手柄。区块控件在相邻正文段落间滑动，遵循系统的减少动态效果设置。
- 正文两侧留白的右键菜单和「更多编辑操作 → 显示选项」提供「限制行宽」「行号」「页面内标题」「链接转脚注」。页内标题与正文使用同一列边距，随正文滚动。末尾空白使用正文右键菜单，菜单打开时保留与当前位置文字高度匹配的闪烁插入光标。限宽、行号和页内标题在工作区内记忆。
- 编辑和阅读时，Windows 按住 Ctrl 点击 HTTP 或 HTTPS 外链可在系统默认浏览器打开，macOS 使用 Command。
- 编辑表格时，鼠标靠近行缝或表格底边，左侧显示插行加号；靠近列缝或表格左右边缘，顶部显示插列加号。鼠标位于单元格中间时，左侧和顶部显示 Milkdown 拖动手柄。拖动时预览随指针移动，落点线吸附到目标行列边界。移到首行的内容成为表头。拖选单元格时描出选区轮廓并提供选区菜单。选中单元格内的文字时，菜单提供链接、行内格式和剪贴板等文字操作。Shift+Enter 在单元格内换行。表格位于文档末尾时，其后保留一行可编辑的正文。
- 编辑时光标进入标题、粗体、斜体、删除线、行内代码或链接会显示对应 Markdown 标记，光标离开或编辑器失焦后收起。粗体标记显示时，可以点击标记内部定位光标。修改标记后按 Enter 或移开焦点应用，Esc 取消。H1–H6 标题可折叠同一级或更高层级标题之前的内容，标题左侧箭头和折叠时的末尾省略图标均可操作。
- 光标进入引用段落时显示 Markdown 引用前缀 `>`，嵌套引用按层级显示。引用首行支持 `[!INFO]`、`[!WARNING]` 等标注，可通过插入命令选择类型，也可在标记后写自定义标题。光标进入标题行时显示标记，失焦后恢复排版。
- 光标进入列表项时显示 `-`、实际序号或任务状态 `[ ]`、`[x]`。点击任务标记可切换完成状态，移出列表项或失焦后恢复排版。
- 代码块获得焦点时显示 Markdown 围栏，可编辑开头的语言标识。失焦时点击右上角语言标签也可修改。代码区内全选仅选中当前代码。右键菜单提供剪切、复制、纯文本粘贴和全选代码，菜单打开期间围栏保持可见。
- 支持 `==高亮==`、`$…$` 行内公式、由独立 `$$` 行围住的块公式，以及 `mermaid` 代码块。行内公式聚焦后显示完整 Markdown 源码，用 Enter 保存。块公式和 Mermaid 图表悬停时显示边框和右上角源码按钮，点击图形或按钮展开等宽字体的源码。Mermaid 编辑期间隐藏预览并暂停渲染，失焦后更新图表。块公式可用 Ctrl 或 Command 加 Enter 保存，Esc 取消。
- 脚注显示 `[^标识]` 引用和文末的 `[^标识]:` 定义，同时粘贴 Markdown 引用和定义时会识别脚注。插入脚注或点击已有引用时，在引用处的浮层中编辑正文，保存后光标留在引用处。
- 「链接转脚注」默认值在通用设置中配置。文档显示选项的临时切换只应用到当前文档。启用时，编辑、预览、复制公众号格式和导出排版 HTML 使用脚注，正文保留链接文字或网址，文末显示参考资料。关闭后恢复原链接，Markdown 源文件保留文章中写入的链接。外部链接仍可右键逐条写入脚注。
- 开启「链接转脚注」后，除公众号允许的 `mp.weixin.qq.com` 链接外，正文、表格、嵌入 HTML（含折叠区标题）中的外链及邮件地址统一使用脚注；已有脚注中的外链补全来源地址为纯文本，不再嵌套编号。编辑显示、预览和发布投影共用同一份编号与来源计划，切换开关不改写原始 Markdown。
- 「复制公众号格式」在渲染前及最终 HTML 中再次检查外链。仍有未转脚注的外链时明确报错，不静默丢掉目的地址；复制结果只保留标准 HTTP/HTTPS 的 `mp.weixin.qq.com` 链接，脚注编号保留文字并去掉公众号不支持的页内跳转。编辑器、预览及 HTML 导出保留脚注跳转。
- 编辑模式下全选正文并复制会写入 Markdown 源码。阅读模式允许选择、复制和查找。分享菜单集中公众号格式复制及各类导出。
- 编辑器「更多编辑操作」提供「复制 Markdown」。导出 Markdown 成功后，在导出操作区提供「在文件夹中显示」入口，不另发成功通知。
- 预览随 Markdown 和公众号主题更新，复杂公式和流程图适度节流。
- 编辑器布局、字号、换行、制表符和主题不直接继承 Radix 的表单控件排版设置。
- 编辑区的 H1–H6、正文段落、引用及提示块从所选公众号主题的最终生效样式读取上下内外边距；标题的装饰边框位置、粗细、线型及文字内缩也与主题一致，主题背景使用对应的工作区色阶。文章主题的装饰线按主题定义展示，不受界面控件 0.5px 边框限制。切换主题时同步更新并清除旧装饰；编辑区字体、工作区配色、行宽及编辑控件保持各自用途，列表和表格单元格的段落不套用正文段距。
- 普通引用的背景透明度、四边装饰、文字对齐与斜体遵循所选主题；提示块使用统一的信息、警告、成功和危险语义配色，编辑、阅读及发布保持同一类型含义。
- 引用的普通段落和末尾段落分别采样，末段归零规则不得覆盖段间距；单段、多段引用和提示块通过 Chromium、WebKit 的计算边距及实际段间距离回归，运行方式见 `tests/browser/README.md`。
- 列表缩进和段距、表格边框与单元格内边距、代码块及语言栏布局使用同一主题取值。紧密列表、松散列表和表格内的段落分别处理；保留表格选区及编辑控件，代码激活时仍可编辑源码。GZH 下划线强调仅应用于正文和列表，不额外装饰普通标题、表格文字或提示标题。
- 任务列表在编辑区保留可切换状态，在预览、公众号复制和 HTML 导出中使用静态勾选标记，不依赖表单控件；任务标记后的空格和制表符采用同一解析约定。

### 5.3 笔记属性

- 新建笔记允许没有标题，默认聚焦正文。编辑区工具行提供排版与发布入口。
- 属性提供目录、标签、摘要、状态和发布链接。有来源时显示来源信息。
- 内容属性抽屉从右侧滑入，收起时向右滑出，遵循系统的减少动态效果偏好。抽屉默认只显示有值的属性。每行由类型图标、属性名和值组成，点击值可直接编辑，输入边界随悬停或聚焦显示。「添加属性」提供尚未显示的内置字段和自定义属性入口。自定义属性可通过类型图标切换文本、日期和标签，也可在同一菜单中移除。标签逐个输入或选择历史建议，支持回车确认及独立移除。
- AI 聊天中的内容属性提案来自当前全文。标题、摘要和建议标签可分别勾选，确认后写入。新增标签与现有标签合并去重，替换标题或摘要前显示当前值，保存成功后标记已写入。

### 5.4 命令面板和快捷键

命令面板负责快速打开笔记、执行「新建笔记」「导入链接」「导入 Markdown」「切换预览」「复制公众号格式」等动作。面板在工作区上方居中浮动，打开即聚焦输入框，顶部只显示输入框和关闭按钮。支持中文关键词、键盘上下选择、回车执行、Esc 或点击外部关闭。

| 操作 | Windows | macOS |
| --- | --- | --- |
| 打开命令面板 | Ctrl + K | Command + K |
| 新建笔记 | Ctrl + N | Command + N |
| 手动立即保存 | Ctrl + S | Command + S |
| 打开全文搜索 | Ctrl + Shift + F | Command + Shift + F |
| 编辑 / 预览切换 | 在设置中查看并可自定义 | 在设置中查看并可自定义 |

切换编辑视图的已设置快捷键显示为灰底按钮；未设置时显示灰底键盘图标和「点击设置」。点击后变为自动聚焦的录入框，旁边提供「ESC 取消」。点击取消或按 Esc 保留原绑定；录入有效组合后立即保存并恢复按钮。右侧垃圾桶图标用于清除绑定，未设置时禁用。保留已有绑定，检查常用系统、工作区和编辑器快捷键冲突。输入法组合及长按重复事件不触发切换，快捷键随工作区迁移包保存。

### 5.5 反馈与错误

本节的状态可见、错误可识别和辅助技术可感知原则参考 [Nielsen 可用性原则](https://www.nngroup.com/articles/ten-usability-heuristics/)、[WCAG 状态消息](https://www.w3.org/WAI/WCAG22/Understanding/status-messages.html)及[错误识别](https://www.w3.org/WAI/WCAG22/Understanding/error-identification.html)。固定 1 秒、按钮颜色、图标动画与错误区预留方式是本项目的统一实现约定，不是上述标准规定的唯一方案。

#### 5.5.1 按钮状态与重复操作

- **覆盖所有按钮**：文字按钮、图标按钮、工具栏、菜单动作、设置页、弹窗及窗口操作都须响应触发；鼠标、键盘和同一动作的快捷键遵循同一状态。原生系统控件保留系统反馈。
- **即时反馈**：触发后立即显示按下或处理中状态。复制、保存、测试连接等动作在原按钮内改变背景色及文案，例如「复制」→「复制中」→「已复制」；不得等网络请求结束才首次反馈。
- **真实完成**：网络及其他异步操作的处理中状态持续到请求及决定结果的必要步骤结束。不得用固定计时器推断成功或提前恢复；无真实进度时使用不定进度，不编造百分比。取消文件选择等主动取消不显示成功或失败。
- **菜单关闭后的反馈**：菜单动作的反馈必须接到关闭后仍可见的对应条目、标签页或触发控件中。复制标题、工作区路径时，在该入口显示处理中和结果文案、背景及图标状态；图片复制和另存为在对应图片附近显示操作反馈，隐藏或移除原图片时不将反馈留在其他文稿上。不得只记录内部状态，也不为展示反馈阻止菜单正常关闭。
- **结果与恢复**：真实操作结束后，仍存在的按钮显示 1 秒结果反馈，再恢复原文案、背景和图标。成功使用 Radix 语义成功色及「已复制」「已保存」等内部状态；失败使用语义错误色及失败状态。处理中和这 1 秒内均禁止重复触发，鼠标、键盘、快捷键和其他重复入口不能再次提交同一动作。禁止重复提交只限制当前动作，不阻塞无关操作或可用的取消入口。
- **图标反馈**：有图标的按钮在原图标位置替换为对应状态动画，处理中使用进度动画，结果使用简短的成功或失败图标动画，不旋转原业务图标来伪装加载；图标与按钮尺寸保持稳定。遵循[减少动态效果原则](https://www.w3.org/WAI/WCAG22/Understanding/animation-from-interactions.html)，启用 `prefers-reduced-motion` 时改用静态状态图标和可感知文案。
- **维持操作语义**：导航、展开和切换按钮以实际选中、展开或开关状态反馈，不显示虚假请求进度；1 秒后只撤去临时反馈，不回退实际状态。打开、关闭或删除使原按钮消失时，不为展示结果而延迟动作。连续编辑命令（如撤销）保留其正常连按语义，不套用任务提交锁定。
- **布局与可访问性**：提前按最长状态文案预留按钮宽度与图标位置，状态变化不挤动相邻元素。优先使用原生按钮语义；如使用 `aria-disabled` 保留焦点，必须实际拦截触发。处理中暴露忙碌状态，状态变化通过合适的 `role="status"` / live region 提供给读屏，不移动用户焦点。

#### 5.5.2 成功与失败提示

- 成功仅使用按钮内部反馈或实际内容变化，不额外显示成功文案、Toast 或弹窗。保存状态、连接状态等持续业务信息仍保留；「已复制」只表示剪贴板写入成功，不能表述为公众号已发布。
- 失败在对应控件或操作行附近显示红色小字，字号不小于 12px，使用 Radix 错误色令牌，并保证普通文字至少 4.5:1 的[对比度](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html)。错误文本说明失败事项及可执行的下一步，不只显示错误码，不依靠颜色或 Tooltip 单独传达错误。
- 错误文案区在初始布局中就预留固定空间；未出错时保留尺寸且不参与读屏播报。长文案在预留区内换行或滚动，不截断唯一的恢复说明，也不临时撑开操作区。紧凑单行区可省略，但完整原因须能通过键盘聚焦的详情入口获取，不能只靠鼠标悬停。
- 错误文本独立于按钮的 1 秒恢复计时，保留到用户修正相关输入、重新执行或主动关闭；不能随按钮恢复自动消失。输入错误关联对应字段和无效状态，操作错误提供合适的 live region；不让每次渲染重复播报。
- 失败保留用户输入、编辑草稿和可重用的任务参数。「重试」入口须重新执行真实任务，不清空内容后让用户重填；不能重试的操作说明可行的处理方式。

#### 5.5.3 后台任务与业务反馈

- 后台任务使用靠近任务的进度区或状态栏；不可逆操作才使用确认对话框。确需用户处理的后台事件可使用通知，不能用通知替代相关操作区的错误原因或重复播报按钮成功结果。
- 无 S3 图床时保留写作与本地预览，公众号带图发布使用「按正文顺序逐张处理图片」流程。
- 数据库备份可独立填写 S3 配置，也可复制已启用图床的配置和凭据。
- 「工作区迁移」在设置左侧有独立入口。迁移包包含数据库、本地素材与界面设置，导入和导出进度显示在对应操作按钮上，导出成功在对应按钮中反馈，不重复显示成功通知。导入校验后需确认恢复并重启。系统凭据需在新设备重新填写。
- 空状态提供「新建笔记」「导入链接」等直接操作。并排按钮使用统一高度并留出间距。

### 5.6 通用交互原则

以下条目采用公开标准与成熟交互模式；链接为依据，具体界面仍使用本项目既有组件和视觉令牌。

| 规则 | 项目要求 | 依据 |
| --- | --- | --- |
| 一致且可预测 | 同一动作使用一致名称、图标和状态表达；切换字段不意外提交、跳页或改变焦点。必要的上下文变化提前告知。 | [Nielsen：一致性与标准](https://www.nngroup.com/articles/ten-usability-heuristics/)、[WCAG 3.2.2](https://www.w3.org/WAI/WCAG22/Understanding/on-input.html) |
| 用户可退出、可恢复 | 普通编辑优先提供撤销；永久删除、覆盖恢复等不可逆操作明确对象与后果并确认，危险动作不设为默认焦点。取消保留原内容，不能把关闭进度界面等同于任务已取消。 | [Nielsen：用户控制与错误预防](https://www.nngroup.com/articles/ten-usability-heuristics/)、[APG 模态对话框](https://www.w3.org/WAI/ARIA/apg/patterns/dialog-modal/) |

| 控件名称与状态可理解 | 按钮名称描述动作，图标按钮提供可访问名称；表单有持久标签，不能只用 placeholder。开关及展开控件暴露真实状态，Tooltip 仅补充说明。 | [APG 按钮模式](https://www.w3.org/WAI/ARIA/apg/patterns/button/)、[WCAG 3.3.2](https://www.w3.org/WAI/WCAG22/Understanding/labels-or-instructions.html) |

## 6. 桌面系统适配

### 6.1 窗口

Windows 和 macOS 的目录导航、文档标签共用一条高 40px、延伸到窗口顶边的标题栏，左栏与编辑区之间保留可拖动的细分割线。Windows 的窗口按钮在右侧。macOS 左上角的原生按钮和导航图标垂直居中，右上角的应用工具距窗口边缘 12px。侧栏展开和收起的整个过程中都为原生按钮保留空间。标题栏空白区域可拖动窗口，双击可缩放或还原。关闭窗口进入工作区保存和退出流程。

### 6.2 原生行为

- 支持系统浅色/深色变化，保留用户显式外观选择。
- 支持系统文件选择、Markdown/HTML 导出目录、剪贴板图片、拖拽文件和外部 URL。
- 可点击区域、右键菜单、滚轮、触控板滚动遵循系统习惯。输入框使用工作台的系统右键菜单，选中文本后可剪切、复制或删除，粘贴使用系统剪贴板。其他区域使用工作台菜单。
- 设置在工作区上方居中打开，保留原内容和选区。点击背景时保持打开，可用关闭按钮或 Esc 退出。左侧可按设置项名称搜索，并按工作区、服务和存储导航；右侧独立滚动。更换分类保留本次打开设置期间尚未提交的表单内容。
- 设置选项的说明应写清用途。涉及性能、权限或数据替换等显著影响时，用橙色说明后果。用途说明和橙色提示均关联对应控件，供键盘聚焦时读屏朗读。界面说明和标签不参与拖选，输入框保留文本选择。Windows 的通用设置提供「硬件加速」，默认启用 GPU 渲染。更改保留在本机，重启工作台后生效。
- 工作区与弹窗使用同一组滚动条颜色。轨道默认透明，滑块细且圆润，悬停和拖动时加深。高对比度模式不覆盖系统颜色。
- 跨平台菜单文本与快捷键提示区分 Ctrl / Command；错误提示和按钮文案默认简体中文。
- 根据 Tauri 当前配置安排窗口最大化、最小化、关闭和安全退出，不让网页式导航替代原生窗口能力。
- 从托盘或菜单栏退出时，隐藏的主窗口保持隐藏，正常保存并退出不恢复窗口。保存失败、退出取消或退出请求发送失败时恢复窗口，展示现有反馈。
- 最小化使用系统行为，Windows 最小化到任务栏，macOS 最小化到 Dock。Windows 托盘图标和 macOS 菜单栏图标从应用启动起常驻显示，打开或恢复主窗口后仍保留，与关闭窗口的设置无关。关闭窗口默认收起到 Windows 托盘或 macOS 菜单栏，可在「设置 → 通用」改为保存并退出。点击工作台图标或再次启动应用可恢复窗口，托盘菜单提供打开和安全退出。主窗口最小尺寸为 1000 × 640 个逻辑像素。

### 6.3 新功能与修复的多端边界

- 所有功能新增和 bug 修复都要评估当前支持端，至少包括 Windows 与 macOS。体验目标一致，窗口控制、菜单、快捷键、文件和剪贴板等遵循各平台原生约定；依据 [Nielsen 的一致性与标准原则](https://www.nngroup.com/articles/ten-usability-heuristics/)，一致不等于抹平系统差异。
- 先区分共享逻辑问题与平台适配问题。单端问题在已有适配层或明确的平台作用域中修复，不能将某一 WebView、系统事件、路径格式或样式补丁无条件应用于全部平台；共享代码变更检查所有相关调用方。
- 按影响检查平台差异，包括 WebView2 / WKWebView、Ctrl / Command、中文输入法、窗口缩放与 DPI、主题、焦点、原生菜单、文件路径和剪贴板；只验证本次涉及的路径，不为未支持端增加兼容分支。
- 交付说明列出实际影响端和验证方式。缺少另一端设备时完成可执行的静态、构建或自动化检查，明确仍需该端实机验证的行为，不把一端通过当作跨端验收通过。

## 7. 公众号预览边界

公众号预览不是普通业务卡片，是**独立内容呈现容器**：

1. 由 Plainly 抽离的渲染器产出主题化 HTML，导出与预览尽量共享同一渲染路径。
2. Radix Theme、工作区全局 CSS 不得污染公众号文章内部的字体、标题、段距、图片样式。
3. 公众号主题应用于编辑正文、文章预览和导出。工作区外观由应用主题独立控制。
4. 预览按 iPhone 18 Pro Max 的机身和屏幕比例呈现，当前文章标题位于正文上方，两者在屏幕内一起滚动。空间不足时外框等比缩小。
5. 图片在编辑预览时使用本地资产解析，可从编辑器上传并替换为图床链接。复制公众号格式时解析图片公开 URL 或提供图片辅助发布。
6. 所有 Markdown 入口（编辑器、导入、MCP）经过既有技术方案定义的 HTML 净化边界。
7. 编辑与排版预览切换时保留当前编辑会话和待保存内容。
8. 手机壳下方提供独立的「亮色 / 暗色」模拟切换，默认亮色，不跟随工作台外观。暗色仅调整预览 DOM 的文字、背景和边框颜色，保留图片原色；切换时保留阅读位置，不修改文章主题、复制或导出内容。这是阅读效果模拟，不保证与所有微信客户端版本逐像素一致。

## 8. 可用性与无障碍

- 所有主要操作有键盘路径；菜单、对话框、弹出层必须支持焦点进入、Tab 导航、Esc 关闭及合理的焦点恢复。
- 编辑正文时，列表和表格优先执行各自的 Tab 命令。没有匹配命令时，Tab 保持正文焦点和光标位置。普通段落可用 Shift+Tab 回到前一个控件。
- 侧栏宽度除鼠标拖动外须支持键盘调整；使用 react-resizable-panels v4 的 Separator，检查焦点样式和键盘调整。
- 重要状态除颜色外还要提供文本或图标；悬浮说明不能是唯一操作入口。
- 浅色与深色模式中，正文、辅助文本、分割线、焦点轮廓具有足够对比度；可用 WCAG 2.2 AA 作为检查基准。
- 尊重 prefers-reduced-motion；降低动画；缩放到 125%/150% 时能正常输入和导航。
- 长文编辑和预览时不频繁抢夺焦点或滚动位置；弹窗关闭后回到触发控件或原编辑区。

## 9. 组件实现约定

建议的最小结构，不提前建立独立设计系统仓库：

~~~text
apps/desktop/src/
  app/
    DesktopShell.tsx
    theme.ts
  components/
    workspace/
      ExplorerPane.tsx
      DocumentTabs.tsx
      WorkspacePanels.tsx
      StatusBar.tsx
    common/
      CommandPalette.tsx
  features/
    inbox/
    references/
    articles/
    editor/
    publishing/
  styles/
    tokens.css
    desktop-shell.css
~~~

- Radix Theme 在应用根部初始化；全局视觉变量在 tokens.css 集中定义。
- 工作区自定义组件使用语义类名，避免依赖 Radix 内部 DOM 层级写大量穿透 CSS。
- 侧栏宽度及可见性、编辑器显示模式属于界面偏好，可以保存在 app_settings 或已存在的本地界面设置服务。
- 不为一次性的页面样式建立独立抽象；一套按钮、一套弹窗、一套通知交互即可。
- 根据当前仓库技术方案，将自动保存、图片清理、S3、MCP 和 AI 的真实业务逻辑留在既有服务层；界面只承担发起操作与结果表达。

## 10. 开发验收清单

在现有实施计划中同步落实，不新增前置 UI 原型关卡：

| 阶段 | 应落地的 UI 范围 | 检查重点 |
| --- | --- | --- |
| P0 工程底座 | Radix Theme、基本工作区外壳、编辑器与预览区、基础窗口 | 可运行、布局连续、主编辑区不被卡片挤占 |
| P1 内容管理 | 目录树与图标、标题栏标签页、自动保存反馈、新建内容菜单 | 鼠标键盘可快速切换内容，写作流畅 |
| P2/P3 素材与公众号 | 图片粘贴状态、主题切换、公众号预览、复制与导入反馈 | 预览样式隔离，图片与内容位置对应 |
| P4/P5 MCP、AI、备份 | 设置表单、模型配置、任务/错误提示、只读及写入权限表达 | 错误可理解，后台功能不打断编辑 |
| P6/P7 回归与发布 | 明暗主题、缩放、Windows/macOS、键盘无障碍与兼容性 | 实际截图和操作验收，真实公众号粘贴测试 |

逐项人工检查：
1. 1360×840 和 1000×640 下，创建文章、编辑、预览、复制无需跨多个页面跳转。
2. 资源导航可折叠和调整宽度，编辑与公众号排版预览可切换，关闭再打开保留布局偏好。
3. 文章列表数百条时可顺畅滚动；打开多个标签不出现重复文章实例。
4. 全部常用操作存在快捷键或明确菜单入口；中文输入法正常输入。
5. 工作区浅色、深色和 125%/150% 缩放下可读；公众号主题不污染应用外观。
6. 网络断开时本地写作和图片预览可用；相关功能提示准确。
7. 保存与复制成功反馈对应真实动作，用户能区分本地保存、S3 上传与公众号后台保存。
8. 受影响按钮立即反馈；异步状态持续到真实完成，结果展示 1 秒后恢复，处理和反馈期间鼠标、键盘、快捷键及重复入口不能重复提交；切换和连续编辑命令保持原语义。
9. 成功无额外提示；失败红字在预留区域内显示，长错误和缩放不引起布局跳动，按钮恢复后错误仍可阅读和处理。
10. 图标状态、减少动态效果、键盘焦点、读屏状态和拖动替代路径按受影响范围检查。
11. 新功能与 bug 修复均完成多端影响评估，平台专用补丁有明确作用域；Windows / macOS 的实测与未验证项分别记录。

### 同步连接与后台状态

- 普通连接只填写服务地址、连接密钥和设备名称，沿用 `SettingRow`，不展示认领、加入、初始化方向或基线模式。
- 本地尚无共同基线且业务内容非空时，连接区显示“连接后将合并本地与云端内容；同一内容存在不同修改时，会保留双方版本供你处理。”沿用设置行辅助文字，并通过 `aria-describedby` 关联原连接按钮；说明与进度、成功和错误反馈分开，不新增确认步骤。空库及已有基线的重新授权不显示。
- 正常连接后，常用区域只保留「复制连接信息」和「立即同步」两个操作，显示当前设备名称。复制操作读取已保存的密钥；连接凭据失效时自动显示重新连接表单，不重复提供输入密钥入口。设备列表在打开设置、同步完成和窗口切回时刷新，不提供独立刷新按钮。设备撤销、更换连接密钥、指定原设备身份恢复和「采用云端内容恢复本机」集中放入默认折叠的高级操作，保留必要的失效与恢复影响说明。
- 设置页和确认弹窗统一遵循第 5.5 节的按钮状态与错误规则。同步失败原因放在「复制连接信息」「立即同步」所在行按钮左侧的固定预留区，紧凑显示时提供可聚焦的完整详情入口。连接状态、任务进度、恢复前校验结果与必要的操作说明仍保留。
- 不新增按下缩放等装饰动画；必要的颜色过渡使用约 250ms ease-out，状态图标按第 5.5 节处理。真实任务结束后按钮展示 1 秒结果，这段时间仍禁止重复触发，但不把任务继续标记为进行中；各按钮独立计时，组件关闭时清理计时器。已移除的行或已关闭的表单不为展示结果而延迟更新。
- 设备已连接和内容同步完成分别反馈。展示需要重新连接、等待云端初始化、正在处理上传任务、已下载等待应用、冲突、暂停与错误；最近检查时间使用当前会话的实际成功记录，未检查显示“等待检查”。
- 左下角状态栏同步展示图标和状态文字，点击打开同步设置。连接、下载、合并和同步阶段使用实际原生状态，避免显示推算百分比。高级操作使用线性展开箭头并保留底部留白，合并成功提示保持单行。
- 浏览同步设置页不阻止已下载内容自动应用；切换到其他设置页、打开确认对话框、执行设置操作或文稿与画布尚未就绪时继续等待，并在连接状态和左下角状态栏显示具体原因。切换页面、结束设置操作及编辑焦点变化后及时重新检查，本地检查不额外触发网络交换。
- 设置打开期间订阅原生状态变化。窗口从后台恢复为可见且有焦点时，合并重复焦点与可见性事件，主动刷新本地状态并请求一次远端检查；最近成功交换（含手动同步）不足 30 秒时跳过本次远端检查，不安排延后补查，本地刷新与安全应用照常执行。前台请求遵守失败退避，不刷新最近成功时间；手动同步和既有立即唤醒不受该间隔限制。远端检查独立于能否安全应用，失焦、最小化和隐藏不停止原生上传与同步调度，已下载内容也可在后台自动应用。应用前等待工作区加载、文稿保存和画布操作完成；后台不因残留的输入框焦点等待返回前台，前台编辑期间仍保留输入保护。关闭到托盘先保存文稿与画布，保存失败保持窗口可见并使用现有错误反馈。
