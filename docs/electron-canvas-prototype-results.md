# Electron 网页画布原型验证记录

## 结论

2026-11-18 在本机 Windows 的 Electron 45.3.4 / Chromium 156.0.8078.100 上，独立原型通过同层实时缩放验证。网页直接挂在 React Flow 节点内部，随父容器变换；没有在截图与实时网页之间切换，没有逐帧修改网页窗口尺寸、网页缩放或滚动位置。

这支持进入迁移成本评估，不代表已迁移工作台。正式 Tauri 应用、其数据库及调用路径均未修改。原型源代码和运行方法见 [原型说明](../experiments/electron-canvas/README.md)。

## 实测

两次有效记录对应 UTC `2026-11-18T04:07:04.529Z` 和 `2026-11-18T04:07:30.951Z`。每组包含 30 段平滑缩放，另测 10% 和 300% 边界。

显示比例之间的布局尺寸差异属于各自初始布局；每组内缩放、平移及裁切过程中保持不变。网页初始化后没有新增改变布局的 resize 记录，实例标识保持不变。

实际桌面测试将原型窗口置顶，确保颜色标记未被其他普通窗口遮挡。100% 组的 175 次采样和 150% 组的 428 次采样处于前台，其余采样期间仍保持置顶且实际屏幕颜色正确。这里记录的是采样观察结果，不声称捕获了显示器呈现的每一帧。

## 其他验证

- 本地网页与主界面使用不同端口，属于跨域加载；保留禁止 iframe 嵌入的响应头。没有修改站点响应头或禁用浏览器 webSecurity。
- 网页颜色标记在缩放期间持续变化，两个颜色均进入合成画面，证明没有用静止图替代实时内容。
- 左、上、右、下四边分别检查可见区域内网页仍被绘制、画布外没有网页颜色泄漏；完全移出和返回后布局与滚动位置保持不变。
- Windows 原生滚轮和点击通过缩放后卡片的位置命中真实网页，完成滚动和链接导航。点击前等待滚轮惯性结束，避免用过期链接坐标测试。
- example.com 的真实 HTTPS 页面成功加载，网页视口在 10%、55%、130%、300% 的画布比例下保持不变。
- 主界面和网页的 `require` 不可用，网页的 `process` 不可用；未向网页提供工作台业务桥。

原始数据和截图位于 `experiments/electron-canvas/artifacts/scale-1/` 与 `scale-1.5/`。类型检查命令和自动验证命令见原型说明。

## 迁移含义

如果最终采用该渲染路线，需要以 Electron 替换 Tauri 的桌面宿主。可以复用 React / React Flow 界面、画布模型和 SQLite 数据；Rust 业务逻辑需要从 Tauri 绑定中分离，通过新的通信适配继续使用。窗口、文件对话框、剪贴板、系统菜单、打包及更新等原生能力需要逐项适配。

本轮没有验证 macOS、Linux、高刷新率显示器、长时间运行、多张重型网页，以及微信公众号登录或风控页面。example.com 的通过不能外推为所有网站兼容。

Electron 官方仍对 `<webview>` 的长期稳定性给出明确提醒，因此目前建议是进入迁移可行性和维护成本评估，不直接替换现有应用。[官方说明](https://www.electronjs.org/docs/latest/api/webview-tag#warning)
