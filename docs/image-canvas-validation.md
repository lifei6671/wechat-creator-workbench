# 图片画布验收记录

日期：2026-11-28。依据[已批准的第二版原型](prototypes/image-canvas/index-v2.html)和[技术方案](image-canvas-technical-design.md)实现，范围包括普通正文和专题中的文章正文。专题临时文本卡片没有图片画布入口。

## 实现范围

正文图片右键打开统一的图片画布。单选、多选和画板选区决定显示哪些编辑工具。工程自动保存到工作区，成品保留不可变场景快照；重新打开历史成品可恢复当时的图层。正文应用由原生事务同时登记成品、快照和正文版本，原生成功后才发布编辑器事务，形成一个撤销项。

工程原图和背景通过私有导入及原始哈希读取路径使用。输出仍可使用图床，但正文保留精确素材身份；发布时解析公开地址。工程、原图和成品复用现有私有同步服务，协议升级为 3。

工作区只分配视口大小的 Canvas。预览按可见范围和屏幕尺寸解码；输出按实际画板范围及倍率解码，释放离场与临时资源。图片限制沿用 20 MiB、16000 像素边长和 4000 万像素；工程最多 100 个图层，场景 JSON 最多 384 KiB。

## 打开流程与紧凑布局增量

加载阶段与编辑阶段使用同一全屏尺寸、画布底色与紧凑标题栏，样式在宿主中提前载入。图片画布不参与通用模态的透明度、缩放与遮罩过渡；加载弹窗卸载时不恢复正文焦点，实际编辑窗口接管焦点。普通弹窗与裁剪、添加图片窗口保留既有交互。

左右顶部工具栏均为 40px 高。左侧保留返回箭头与「编辑图片」，右侧保留撤销、重做、缩放、适应画板和全选。属性面板固定标题及导出区，中间属性独立滚动，以适应 1000×640 的原生最小窗口；表单的禁用状态仍由内部 fieldset 统一管理。

变更区域可见元素：返回箭头用于保存草稿后回到正文；标题用于辨识当前任务；打开状态用于反馈工程读取；撤销与重做用于修正编辑；缩放与适应画板用于查看输出范围；全选用于批量操作；属性滚动区用于访问全部设置；导出区用于随时输出成品；草稿状态用于判断是否已保存。其余可见文案见上表。

本轮验证、截图、构建及独立评审记录见本机 `output/image-canvas-compact`。本轮不涉及原生 API、场景格式或同步协议变更。

## 返回点击范围、背景预设与默认 WebP

左上返回按钮覆盖整块标题栏，标题、图标和留白区域共用同一保存后返回动作；保留标题的语义，支持键盘激活，操作进行中整块禁用。加载阶段保持相同布局。

纯色与渐变各提供 12 个预设，按明度从浅到深排列，覆盖浅色、中间色和深色。纯色同时拉开色相与明度差异；渐变使用由浅到深的四色及不同方向，补齐中间明度档位，缩略图与画布使用相同色阶和方向。新背景仍默认深蓝色，适合夜间截图；修改渐变端点颜色保留中间色阶。使用既有场景格式与渲染路径，工程保存、导出和同步保留完整色阶。

新打开编辑窗口默认导出 WebP，仍可切换 PNG/JPG，沿用原有画质和倍率控件。

可见元素及用途：整块返回区域用于更容易地保存并返回正文；纯色预设用于匹配图片明暗；渐变预设用于选择有层次的背景；端点颜色与方向用于调整当前渐变；导出格式用于选择成品编码。本轮没有增加其他功能入口。

## 圆角轮廓与预览边缘修正

画板背景直接绘制圆角轮廓，图片背景按同一轮廓裁切；前景图片使用独立的圆角裁切区域。预览不再使用擦除遮罩，避免四角残留直角边线及截断画板阴影。画板外的图片仍可查看、选择和移动，导出仅包含画板内的内容。

变更区域可见元素及用途：背景用于衬托图片，圆角用于调整画板或选中图片的轮廓，阴影用于表现图片层次。本轮不增加控件或文案。原图中已有的边框、圆角和阴影属于图片像素，裁切轮廓不会清除这些内容。

本轮原生圆弧及阴影像素对照、不同背景和 PNG/WebP 倍率验证、截图与独立评审记录位于本机 `output/image-canvas-rounding`。
