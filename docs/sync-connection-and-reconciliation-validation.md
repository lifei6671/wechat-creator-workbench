## Windows 原生窗口

使用独立应用标识 `io.github.lifei6671.wechat-creator-workbench.sync-test-20261119` 和独立工作区运行真正的 Tauri/WebView2 窗口，经本机 CDP 驱动实际编辑器与按钮。同步结果直接读取隔离服务 SQLite，窗口可见性和最小化状态由 Win32 按测试进程 ID 核对，不以网页 `visibilityState` 代替原生窗口状态。

- B01：原生主窗口隐藏时，在实际编辑器保存的内容到达服务端。最小化上传在最终编译版本重新执行并核对 `IsIconic=true`。
- B02：实际编辑器输入后立即点击原生“关闭窗口”；保存握手后 `IsWindowVisible=false`，服务端读取到含末尾文字的内容。最终编译版本上传观察耗时约 352 ms；此数值是本地测试观察，不是性能承诺。
- B03：仅对隔离客户端数据库持有写锁，制造真实保存失败；界面显示“保存失败”，原生窗口保持可见，编辑缓冲文本保留。释放写锁并点击重试后恢复。
- B06：通过实际 IPC 开始退出、取消退出，再编辑并唤醒任务；服务端收到后续内容，应用级调度没有永久结束。最终编译版本观察到约 505 ms 后云端内容更新。
- 收起前画布保存目前由前端集成测试覆盖；没有单独完成真实窗口中“修改画布后立即收起”的验收。

### 实现

- `DesktopShell` 合并 `focus`、`blur`、`visibilitychange`，只在后台转换为可见且有焦点时调用 `syncWake("foreground")`；组件挂载不额外请求远端。恢复同步请求不受输入框、保存队列或画布的安全应用条件限制，应用远端内容仍受这些条件保护。
- 既有 `sync_wake` 增加可选来源。省略仍为立即唤醒；来源位原子合并后由同一个原生任务消费。前台请求提前 `next_pull`，遵守 `retry_at`；同批存在立即来源时保留立即执行语义。
- 暂停、退出、已知凭据拒绝及待应用完整快照保持原有处理边界；完整快照等待期间保留提前的检查时间。没有新增网络任务、调度计时参数或业务表。
- `sync_activity` 在未连接时也返回本地状态，增加 `hasLocalContent`，直接复用首次合并的 `empty_local`。设置页在非空、未建立共同基线的普通连接区域展示指定说明，以 `aria-describedby` 关联原连接按钮；说明独立于成功、错误与运行进度反馈。
